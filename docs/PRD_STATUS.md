# PRD 完成度审查（真人视角）

审查对象：PRD v0.4 V1 闭环。审查方式：以工作室制片打开 `/app` 后，能否不读源码走完全程。

## 结论

**可以形成一条可演示的本地生产闭环，但还不是可上线的商业 SaaS。**

后端 P0 对象和接口大多已经落地（本地文件 / mock AI）。这次把工作台改成浅色朱红样式，并补上分格工作台、成员页、任务页、项目结构树、页面预览、成员改角色、项目成本。真人现在能：登录 → 配模型 → 建剧集 → 导入漫画 → 看原图 → OCR/上色/出视频 → 建镜头和台词 → QC/导出/冻结。

真人仍然做不到的，是把第三方模型和远程 ComfyUI 真正跑通。这些按当前产品决策可以继续 mock，但必须写清楚。

## 功能拆分（按新 UI）

| 导航 | 对应 PRD | 真人能不能用 |
| --- | --- | --- |
| 登录工作室 | 登录/注册 | 能。没有忘记密码。 |
| 总览 | Dashboard / 项目列表 | 能建剧集、切当前项目。立项向导是默认 Brief，不是逐步表单。 |
| 导入 | 漫画/PDF 导入 | 能上传并生成章节页格。 |
| 分格 | 页面/分格工作台 | 能看树、看原图、OCR、分析、上色、出视频。 |
| 上色 | 参考上色 / 角色 | 能单格、批量、存参考和角色。没有遮罩画笔。 |
| 镜头 | Shot / Animatic / 时间线 | 能建 Shot 和 Timeline。没有可视化多轨剪辑。 |
| 音频 | 台词 / BGM | 能建台词和 BGM。配音/字幕要打 API 或后续在分格结果上点。 |
| 审片 | QC / 导出对象 | 能创建 QC 和导出记录。 |
| 导出 | 审片包 / 冻结 | 能建审片包、preflight、freeze ZIP。 |
| 模型配置 | Provider / ComfyUI / Workflow | 能填 Key 和地址并保存。真实调用未接通。 |
| 成员 | RBAC | 能邀请已注册用户、改角色。 |
| 任务 | Job 队列 | 能看任务、运行、重试、取消。Worker 仍是进程内同步。 |
| 设置 | 会话 | 只存 token / team / project。 |

命令盘可打开次要页：链路向导、报表、合规下载、通知、帮助、P2。

## P1

PDF 导入、分格手动修正、色彩策略、字幕翻译、错误日志：API 在，工作台只覆盖了 PDF 导入和报表里的错误计数。

## P2（明确不在 V1）

私有化、云 ComfyUI 池、画布编辑、专业时间轴、实时协同、训练平台、ProRes/DCP：只有配置占位，不应算完成。

## 上线前仍缺（不是这次 UI 能假装补上的）

- 真实第三方 AI 和 ComfyUI `/prompt` 执行
- 异步后台 Worker
- 对象存储（现为本地盘）
- API Key 加密存储
- 忘记密码、邮件邀请未注册用户
- 可视化时间线和客户外链审片播放器
- 浏览器 E2E（Playwright）

## 验收口径

如果问「PRD V1 工作台能不能给工作室演示本地闭环」：可以。

如果问「是不是已经做完、可以卖」：没有。缺真实模型、异步队列、存储和审片播放体验。
