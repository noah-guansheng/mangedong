# PRD 完成度审查（真人视角）

审查对象：PRD v0.4 V1 闭环。审查方式：以工作室制片打开 `/app` 后，能否不读源码走完全程。

## 结论

**本地演示闭环已经收口：登录、立项、导入、分格生产、审片播放、导出都能在工作台里点完。**

它仍然不是可上线的商业 SaaS。真实第三方模型和远程 ComfyUI 会先尝试连接；连不上时回退本地占位文本 / Ken Burns MP4。没有 SMTP、没有 S3、视频也不是 TV 番剧级成片。

## 明确做不到（不要假装）

| 能力 | 现状 | 缺口 |
| --- | --- | --- |
| 任务队列 | 文件 SQLite 下启动后台线程 worker；测试内存库默认同步 | 未做独立进程/多机 |
| 对象存储 | 本地磁盘 `MANGEDONG_STORAGE_DIR` | 未接 S3 |
| 第三方 AI | 保存并加密 API Key；OCR/分析先试 chat completions | 无密钥或超时则本地占位 |
| ComfyUI | 保存远程 URL；健康检查与 `/prompt` 真连，失败回退 | 本环境通常无 8188 |
| 上色 | 本地 OpenCV LUT + PNG | 不是 ComfyUI 出图 |
| 视频 | 先写 Ken Burns MP4，再尝试 ComfyUI | 不是 TV 番剧级成片 |
| 邀请/重置 | 未注册邮箱可邀请并返回 token；忘记密码返回 reset_token | 无 SMTP |
| 审片播放 | 审片页可播 MP4 并按时间码批注 | 不是专业 NLE |
| API Key 加密 | XOR+HMAC `enc:` 存库 | 不是 KMS/vault |

## P1 / P2

PDF 导入、分格手动修正、色彩策略、字幕翻译、错误日志：API 在，工作台覆盖了 PDF 导入、报表错误计数和分格生产。

私有化、云 ComfyUI 池、画布编辑、专业时间轴、实时协同、训练平台、ProRes/DCP：只有配置占位，不算完成。

## 验收口径

如果问「PRD V1 工作台能不能给工作室演示本地闭环」：可以。

如果问「是不是已经做完、可以卖」：没有。缺真实成片质量、邮件、对象存储和独立 worker 进程。
